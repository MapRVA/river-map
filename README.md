# RiverMapRVA

A map for recreating in the James River, putting all the informaiton you need in one place!

## Data Sources

* CSO Events - [Richmond's Real-Time CSO Status map](https://apps.emnet.net/richmond-pub-map-app/?city=47&config=5c0cacee-7e95-4eea-922d-c736c83eb4b9)
* Test Resutls - [James River Watch](https://experience.arcgis.com/experience/a4993d1967c84cb88f1fd3a324c570fc)
* Stream Gauges - [NOAA NWPS API](https://water.noaa.gov/about/api)

## Other Credits

* implemented using [Ultra](https://overpass-ultra.us/docs/) which is in turn powered by [MapLibre](https://maplibre.org)
